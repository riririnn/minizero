# Attention Map および 重みパラメータ可視化GUI 開発ロードマップ

本ドキュメントは、学習済みのモデル（Transformer/Attentionベース）の内部状態をGUIで可視化・分析するためのロードマップです。

## フェーズ1: 要件定義と技術選定 (目安: 1週間)
- **目的の明確化**:
  - $W_q, W_k, W_v$ の重み行列のヒートマップ・分布の可視化。
  - 推論時の Attention Map (どの入力トークンがどのトークンに注目しているか) の可視化。
  - ※ 将棋環境などを扱う場合、81マスの盤面特徴量がトークンとなるため、盤面上のどのマスに注目しているかのマッピングも考慮する。
- **技術選定**:
  - **バックエンド**: Python, PyTorch (推論およびパラメータ抽出)
  - **GUIフレームワーク**: `Streamlit` または `Gradio` (機械学習モデルとの親和性が高く、PythonのみでインタラクティブなWeb GUIが構築できるため推奨)。
  - **描画ライブラリ**: `Matplotlib`, `Seaborn` (ヒートマップ用), `Plotly` (インタラクティブな描画用)。

## フェーズ2: モデルからのデータ抽出ロジックの実装 (目安: 1〜2週間)
- **パラメータ ($W_q, W_k, W_v$) の抽出**:
  - PyTorchの学習済み重み (`.pth` 等) をロードするスクリプトの作成。
  - `model.named_parameters()` や `state_dict()` から、各Transformerブロック・各ヘッドのQuery, Key, Valueの重み行列を抽出する関数を実装。
- **Attention Mapの抽出 (Forward Hookの活用)**:
  - PyTorchの `register_forward_hook` を使用し、任意の入力をモデルに流し込んだ（Forward pass）際に、計算された Attention スコア行列（Softmax後の出力）をキャプチャして外部に保存する仕組みを構築。

## フェーズ3: 可視化コンポーネントの開発 (目安: 2週間)
- **重みパラメータ可視化コンポーネント**:
  - 行列を2次元のヒートマップとして描画する機能。
  - 重みの値の分布を確認するためのヒストグラム・バイオリンプロットの実装。
- **Attention Map可視化コンポーネント**:
  - 通常の行列ヒートマップ（Token vs Token）の描画。
  - **ドメイン特化の可視化 (将棋盤面など)**: 入力が盤面である場合、基準となるマス（トークン）を選択した際、他のどのマス（トークン）に高いAttentionが割り当てられているかを、将棋盤のUI上に色付けして表示する独自の描画ロジックの実装。

## フェーズ4: GUIアプリケーションの統合 (目安: 2週間)
- **UIレイアウトの設計**:
  - **サイドバー**: 「モデルファイル選択」「可視化対象の選択（重み or Attention）」「レイヤー番号」「ヘッド番号」のセレクトボックス。
  - **メインエリア**: 選択された可視化グラフの表示エリア。
  - **入力コントローラー**: Attention Map表示用に、推論のための入力データ（SGFや任意の盤面状態）をセットできるインターフェース。
- **インタラクションの実装**:
  - UIの入力が変更されるたびにバックエンドで推論が走り、グラフや盤面のハイライトがリアルタイムに更新されるようにする。

## フェーズ5: テスト・改善・デプロイ (目安: 1週間)
- **パフォーマンスチューニング**:
  - 行列のサイズが大きい場合や、複数ヘッドを同時に表示する際の描画遅延を解消するため、Streamlitのキャッシュ機能（`@st.cache_data` 等）を活用して再計算を防ぐ。
- **ユーザビリティの改善**:
  - カラーマップ（Colormap）の調整による値の強弱の視認性向上。
  - 注目すべき極端に大きい/小さいパラメータの自動ハイライト機能の追加。
- **デプロイ (オプション)**:
  - チーム内でツールを共有するために、`Dockerfile` を作成しサーバー上にホストする。

---
## 次のステップ（開発を始めるにあたって）
1. 既存の PyTorch モデルファイル (`.pth` など) を用意する。
2. モデルのネットワーク定義コードを確認し、Attentionが計算されるモジュール（クラス）のレイヤー名や構造を特定する。
3. 手元で `import streamlit as st` を用いて、最小限のGUIプロトタイプ（フェーズ4のレイアウトのみ）を作成してみる。
